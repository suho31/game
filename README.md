# 요트 다이스 · 구룡투

친구와 1:1로 즐기는 웹 게임. PeerJS(WebRTC P2P) 로 서버 없이 직접 연결됩니다.

## 게임

### 요트 다이스

![요트 다이스 게임 화면](images/요트다이스.jpeg)

주사위 5개를 굴려 12가지 족보를 완성하는 게임입니다. 상단 점수의 합이 63점 이상이면 보너스를 받을 수 있습니다.

### 구룡투

![구룡투 게임 화면](images/구룡투.jpeg)

1부터 9까지의 용을 동시에 한 장씩 내서 승부하는 게임입니다. 높은 숫자가 이기지만 1은 9를 이기며, 먼저 2승을 거두면 승리합니다.

## 게임 방법

1. 방장이 **방 만들기** → 4자리 숫자 코드 생성
2. 친구가 코드 입력 후 **참가**
3. 방장이 게임 선택 → 시작
