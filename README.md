# 요트 다이스 · 구룡투

친구와 1:1로 즐기는 웹 게임. **PeerJS(WebRTC P2P)** 로 서버 없이 직접 연결됩니다.

- **요트 다이스** — 주사위 5개, 12족보 + 상단 63점 보너스, 슬롯머신 굴림 연출
- **구룡투** — 용 1~9 동시 제출, 높은 숫자 승(단 **1은 9를 이김**), 숫자는 숨기고 승/패/무만 공개, 대결 끝나면 전체 공개, 2선승제

## 하는 법
1. 방장이 `index.html`을 열고 **방 만들기** → 4자리 숫자 코드 생성
2. 친구가 코드 입력 후 **참가**
3. 방장이 게임 선택 → 시작

## 배포 (GitHub Pages)
이 저장소를 GitHub에 올리고 **Settings → Pages → Branch: main** 으로 설정하면
`https://<아이디>.github.io/<저장소>/` 에서 바로 플레이할 수 있습니다.
파일을 수정해 push할 때마다 같은 주소로 자동 재배포됩니다.
